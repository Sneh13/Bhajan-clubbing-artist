# Bhajan Clubbing Artist

Static website for Bhajan Clubbing Artist.

## Files
- `index.html` — website content
- `style.css` — responsive design
- `script.js` — mobile menu, booking-to-WhatsApp form

## Deploy on Cloudflare Pages
For a plain static site:
- Production branch: `main`
- Build command: `exit 0`
- Build output directory: `/` (root)

Replace the placeholder Unsplash gallery/hero images with your own licensed event photos when ready.
